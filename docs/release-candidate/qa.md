## Harness validity and boundaries

- Production runtime is required. Development localhost intentionally rewrites protected routes to a design preview; runners reject `.local-design-frame`.
- Full Chromium is required for macOS camera capture; headless-shell returned NotSupportedError. Fake camera video supplies real pixels to real media/decoder code. Successful backend responses, scanner results and application routes are never mocked in browser acceptance.
- Browser permission state is cleared before denial. Request abortion and CDP latency simulate failure/slow transport only. Actual emulator airplane mode and Home/resume supplement them.
- Mobile viewport screenshots avoid a full-page CDP capture behavior that reset coarse pointer emulation and activated the desktop gate. Group settings captures wait for animation completion.
- Earlier cross-DM harness retry resent token01 because unloaded history was mistaken for absence. It now requires explicit send/verify mode and uses fresh02 tokens. Earlier duplicate token01 rows are retained honestly in pagination evidence; all message IDs remain unique.
- iOS keyboard autocorrection changed planned tokens. Acceptance compares the actual literal typed/sent by UI, not an invented expected string.
- An ancillary Android Home visibility probe was not counted as a pass: the OS foreground changed to Home but Chrome emitted no document visibility events in that short probe. Exact native-Leave/browser-resume and group offline/reconnect assertions passed independently.
- Component mocks provide regressions only; no component test substitutes for actual native acceptance. API-prepared cross membership and iOS injected scanner callback are not optical decoding evidence.
- Earlier automatic approval blocker was resolved by direct human authorization/access update. No live-test authorization blocker remains.
- Existing user deletions `SupabaseTrafic.png` and `design_assets/Design1.png` remain untouched. Actual Google OAuth and physical-device checks are explicitly deferred. Publishing and store submission are outside scope.
